Файл на проект по ссылке на файлообменник PixelDrain тут - https://pixeldrain.com/u/axVKUkWP
## 1. НАЗНАЧЕНИЕ СИСТЕМЫ

Система предназначена для отслеживания служебных автомобилей в реальном времени. Позволяет контролировать местоположение, скорость, уровень топлива, температуру двигателя и получать уведомления о критических событиях.

---

## 2. ФУНКЦИОНАЛЬНЫЕ ВОЗМОЖНОСТИ

| № | Функция | Описание |
|---|---------|----------|
| 1 | **Карта** | Отображение всех автомобилей на Яндекс.Картах с цветовой индикацией статуса |
| 2 | **Список ТС** | Таблица автомобилей с поиском и фильтрацией |
| 3 | **Статистика** | Круговая диаграмма распределения автомобилей |
| 4 | **События** | Лента событий (превышение скорости, низкое топливо, перегрев) |
| 5 | **Детали ТС** | График скорости, мини-карта, все параметры автомобиля |
| 6 | **Симуляция GPS** | Встроенный симулятор движения для тестирования |

## 5. МОДЕЛИ ДАННЫХ

### Vehicle (Автомобиль)

| Поле | Тип | Описание |
|------|-----|----------|
| id | Int | Уникальный идентификатор |
| plate | String | Государственный номер |
| driverName | String | ФИО водителя |
| model | String | Марка/модель |
| status | VehicleStatus | MOVING / IDLE / OFFLINE |
| latitude | Double | Широта |
| longitude | Double | Долгота |
| speed | Int | Скорость (км/ч) |
| fuelLevel | Int | Уровень топлива (0-100%) |
| distanceToday | Int | Пробег за день (км) |
| currentRoute | String | Текущий маршрут |
| engineTemp | Int | Температура двигателя (°C) |
| lastSeen | Long | Время последнего обновления |

### VehicleEvent (Событие)

| Поле | Тип | Описание |
|------|-----|----------|
| eventId | Int | Уникальный идентификатор |
| vehicleId | Int | ID автомобиля |
| type | EventType | SPEEDING / LOW_FUEL / ENGINE_OVERHEAT |
| description | String | Описание события |
| timestamp | Long | Время события |
| latitude | Double | Широта места события |
| longitude | Double | Долгота места события |

## 6. ПОРОГИ СОБЫТИЙ

| Событие | Код | Условие |
|---------|-----|---------|
| **Превышение скорости** | SPEEDING | speed > 90 км/ч |
| **Низкий топливо** | LOW_FUEL | fuelLevel < 15% |
| **Перегрев двигателя** | ENGINE_OVERHEAT | engineTemp > 105°C |

## 8. ИНТЕРФЕЙС ПОЛЬЗОВАТЕЛЯ

### 8.1 Экран карты (MapFragment)

| Элемент | Действие |
|---------|----------|
| Маркеры | Цвет: синий (движется), оранжевый (стоит), красный (офлайн) |
| Номер в маркере | ID автомобиля + 1 |
| Клик по маркеру | Открывает BottomSheet с информацией |
| Кнопка "+" | Приблизить карту |
| Кнопка "-" | Отдалить карту |
| Кнопка "Центр" | Центрировать карту по всем ТС |

### 8.2 Экран списка (VehiclesFragment)

| Элемент | Действие |
|---------|----------|
| Поиск | Фильтрация по номеру/водителю/модели |
| Чип "Все" | Показать все ТС |
| Чип "В пути" | Показать только MOVING |
| Чип "Стоит" | Показать только IDLE |
| Чип "Офлайн" | Показать только OFFLINE |
| Карточка ТС | Клик → открытие детального экрана |

### 8.3 Экран статистики (ReportsFragment)

| Элемент | Действие |
|---------|----------|
| Круговая диаграмма | Распределение по статусам |
| Всего ТС | Общее количество |
| Общий пробег | Сумма distanceToday |
| Средний расход | Средний fuelLevel |
| Средняя скорость | Средняя speed (только MOVING) |
| Лента событий | Последние 15 событий с цветовой индикацией |

### 8.4 Детальный экран (VehicleDetailActivity)

| Элемент | Действие |
|---------|----------|
| Мини-карта | Позиция автомобиля |
| График скорости | Последние 20 измерений |
| Прогресс топлива | Цвет: красный (<20%), жёлтый (<50%), зелёный (>50%) |
| Карточки предупреждений | Отображаются при fuelLevel < 20 или engineTemp > 100 |

## 9. СИМУЛЯЦИЯ GPS (GpsSimulator)

### 9.1 Параметры симуляции

| Параметр | Значение |
|----------|----------|
| Количество автомобилей | 8 |
| Маршруты | 6 маршрутов по Москве |
| Интервал обновления | 1.5 секунды |
| Скорость | 20-95 км/ч (случайные изменения ±8 км/ч) |
| Расход топлива | -0.002% за тик |
| Температура | 85 + скорость/10 ±2°C |

### 9.2 Маршруты

| № | Маршрут |
|---|---------|
| 0 | Кольцевой (центр) |
| 1 | Север-Юг |
| 2 | Запад-Восток |
| 3 | Бульварное кольцо |
| 4 | МКАД (фрагмент) |
| 5 | Садовое кольцо |

## 10. ТРЕБОВАНИЯ К УСТАНОВКЕ

### 10.1 API-ключ Яндекс.Карт

Добавить в `AndroidManifest.xml`:

```xml
<meta-data
    android:name="com.yandex.mapkit.API_KEY"
    android:value="ВАШ_API_КЛЮЧ" />
```

### 10.2 Разрешения

Приложение запрашивает:
- `ACCESS_FINE_LOCATION` — точная геолокация
- `ACCESS_COARSE_LOCATION` — приблизительная геолокация
- `INTERNET` — доступ к интернету (карты)
- `ACCESS_NETWORK_STATE` — проверка сети

## 11. ЗАПУСК ПРИЛОЖЕНИЯ

### 11.1 Установка

```bash
# Сборка APK
./gradlew assembleDebug

# Установка на устройство
adb install app/build/outputs/apk/debug/app-debug.apk
```

### 11.2 Первый запуск

1. Приложение запросит разрешение на геолокацию → разрешить
2. Автоматически начнётся симуляция 8 автомобилей
3. На карте появятся маркеры

## 12. ИЗВЕСТНЫЕ ОГРАНИЧЕНИЯ

| № | Ограничение | Описание |
|---|-------------|----------|
| 1 | **Симуляция** | Нет подключения к реальным GPS-трекерам |
| 2 | **Фиксированные маршруты** | Маршруты заданы в коде |
| 3 | **Офлайн-режим** | Карты требуют интернет |
| 4 | **Нет экспорта** | Нельзя выгрузить отчёты |
| 5 | **События** | Проверка событий каждые 10 секунд (не мгновенно) |
