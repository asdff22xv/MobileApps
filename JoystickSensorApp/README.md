 1. Работа с сенсорами

## 1. НАЗНАЧЕНИЕ ПРИЛОЖЕНИЯ

Приложение предназначено для демонстрации работы с гироскопом телефона. Пользователь управляет синим кругом на экране, наклоняя устройство в разные стороны. Чем сильнее наклон, тем быстрее движется круг.

---

## 2. ФУНКЦИОНАЛЬНЫЕ ВОЗМОЖНОСТИ

| № | Функция | Описание |
|---|---------|----------|
| 1 | **Управление наклоном** | Круг движется при наклоне телефона в любую сторону |
| 2 | **Отображение данных гироскопа** | Показывает текущие значения вращения по осям X и Y |
| 3 | **Отображение координат** | Показывает текущую позицию круга на экране |

| 6 | **Проверка гироскопа** | Сообщает, есть ли гироскоп на устройстве |
| 7 | **Границы движения** | Зелёная рамка ограничивает движение круга |

## 5. ГИРОСКОП: ТЕХНИЧЕСКОЕ ОПИСАНИЕ

### 5.1 Что измеряет гироскоп

Гироскоп измеряет **угловую скорость** вращения телефона (радиан в секунду).

| Ось | Название | Что измеряет |
|-----|----------|--------------|
| X (values[0]) | Тангаж (Pitch) | Наклон вперёд/назад |
| Y (values[1]) | Крен (Roll) | Наклон влево/вправо |
| Z (values[2]) | Рыскание (Yaw) | Поворот телефона (не используется) |

### 5.2 Диапазон значений

```
Телефон лежит ровно:    X ≈ 0, Y ≈ 0, Z ≈ 0
Наклон влево:           Y ≈ +1.5 рад/сек
Наклон вправо:          Y ≈ -1.5 рад/сек
Наклон вперёд:          X ≈ +1.5 рад/сек
Наклон назад:           X ≈ -1.5 рад/сек
```

## 6. АЛГОРИТМ РАБОТЫ

### 6.1 Получение данных с гироскопа

```kotlin
override fun onSensorChanged(event: SensorEvent?) {
    // 1. Получить значения
    val rawX = event.values[0]  // ось X
    val rawY = event.values[1]  // ось Y
    
    // 2. Фильтрация шума (значения < 0.01 игнорируем)
    gyroX = if (abs(rawX) > EPSILON) rawX else 0f
    gyroY = if (abs(rawY) > EPSILON) rawY else 0f
    
    // 3. Преобразование в движение круга
    val deltaX = -gyroY * sensitivity  // инверсия для интуитивности
    val deltaY = gyroX * sensitivity
    
    // 4. Переместить круг
    gameView.updatePosition(deltaX, deltaY)
}
```

### 6.2 Преобразование осей (инверсия)

| Действие пользователя | Значение гироскопа | Движение круга |
|----------------------|-------------------|----------------|
| Наклон влево | gyroY = +1.5 | deltaX = -1.5 * 2 = -3 (влево) |
| Наклон вправо | gyroY = -1.5 | deltaX = -(-1.5) * 2 = +3 (вправо) |
| Наклон вперёд | gyroX = +1.5 | deltaY = +1.5 * 2 = +3 (вверх) |
| Наклон назад | gyroX = -1.5 | deltaY = -1.5 * 2 = -3 (вниз) |

**Формула:**
- Движение по X = -значение Y × чувствительность
- Движение по Y = значение X × чувствительность

## 7. НАСТРОЙКИ ЧУВСТВИТЕЛЬНОСТИ

| Режим | Значение sensitivity | Скорость движения |
|-------|---------------------|-------------------|
| **Низкий** | 1.0 | Медленное |
| **Нормальный** | 2.0 | Среднее (по умолчанию) |
| **Высокий** | 4.0 | Быстрое |

### Переключение режимов

```kotlin
Нормальный → Высокий → Низкий → Нормальный (циклически)
```

## 8. ФИЛЬТРАЦИЯ ШУМА

### Параметр EPSILON = 0.01

| Значение гироскопа | Результат |
|-------------------|-----------|
| |value| < 0.01 | Обнуляется (игнорируется) |
| |value| ≥ 0.01 | Используется для движения |

**Зачем:** Убирает дрожание круга, когда телефон лежит на столе или пользователь держит его неподвижно.

## 9. ГРАНИЦЫ ДВИЖЕНИЯ

### Зелёная рамка

Круг не может выйти за пределы зелёной рамки, которая отступает от краёв экрана на радиус круга (50 пикселей).

```
Минимальная X = радиус (50)
Максимальная X = ширина экрана - радиус
Минимальная Y = радиус
Максимальная Y = высота экрана - радиус
```

### Код ограничения

```kotlin
playerX = playerX.coerceIn(minX, maxX)
playerY = playerY.coerceIn(minY, maxY)
```

## 12. ЖИЗНЕННЫЙ ЦИКЛ СЕНСОРА

| Метод | Действие | Когда вызывается |
|-------|----------|------------------|
| `onCreate()` | Получение сервиса сенсоров, проверка наличия гироскопа | При запуске приложения |
| `onResume()` | Регистрация слушателя (гироскоп включается) | Приложение стало видимым |
| `onPause()` | Отмена регистрации (гироскоп выключается) | Приложение свёрнуто |

**Важно:** Без отмены регистрации в `onPause()` гироскоп будет работать в фоне и быстро разряжать батарею.

### 16.2 Первый запуск

1. Приложение проверит наличие гироскопа

3. Наклоняйте телефон — круг будет двигаться
4. Кнопка "Сброс" возвращает круг в центр

## 17. ИЗВЕСТНЫЕ ОГРАНИЧЕНИЯ

| № | Ограничение | Описание |
|---|-------------|----------|
| 1 | **Нет акселерометра** | Используется только гироскоп (измеряет скорость вращения, а не угол) |
| 2 | **Нет калибровки** | Нельзя установить нулевое положение |

| 5 | **Нет сохранения позиции** | При повороте экрана позиция сбрасывается |

## 18. ОСОБЕННОСТИ ГИРОСКОПА (ВАЖНО)

### Гироскоп измеряет СКОРОСТЬ вращения, а не угол наклона

```kotlin
// Если вы НАКЛОНИЛИ телефон и ДЕРЖИТЕ его неподвижно:
// Гироскоп покажет 0 (круг остановится)

// Если вы ВРАЩАЕТЕ телефон (меняете угол):
// Гироскоп покажет скорость вращения (круг двигается)
```

**Это нормальное поведение гироскопа.** Для определения угла наклона нужен акселерометр.
