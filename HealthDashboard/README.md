 HealthDashboard (Трекер здоровья) 

## 1. НАЗНАЧЕНИЕ ПРИЛОЖЕНИЯ

Приложение предназначено для отслеживания и анализа медицинских показателей пользователя. Позволяет записывать пульс, давление, шаги, потребление воды, сон и температуру, а также получать оценку этих показателей по медицинским нормам.

---

## 2. ФУНКЦИОНАЛЬНЫЕ ВОЗМОЖНОСТИ

| № | Функция | Описание |
|---|---------|----------|
| 1 | **Добавление записей** | Ввод медицинских показателей через диалоговое окно |
| 2 | **Текущие показатели** | Отображение последних введённых данных |
| 3 | **Оценка здоровья** | Автоматическая оценка каждого показателя (норма/отклонение) |
| 4 | **Статистика** | Средние значения по всем записям (пульс, шаги, давление, вода) |
| 5 | **История** | Список последних 10 записей с датой и временем |
| 6 | **Цветовая индикация** | Разные цвета карточек для разных показателей |

## 5. МОДЕЛИ ДАННЫХ

### HealthData (Одна запись)

| Поле | Тип | Описание | Значение по умолчанию |
|------|-----|----------|----------------------|
| heartRate | Int | Пульс (уд/мин) | Обязательное |
| steps | Int | Количество шагов | Обязательное |
| systolic | Int | Давление верхнее (мм рт.ст.) | Обязательное |
| diastolic | Int | Давление нижнее (мм рт.ст.) | Обязательное |
| waterIntake | Double | Потребление воды (литры) | Обязательное |
| sleepHours | Int | Количество сна (часы) | 8 |
| temperature | Double | Температура тела (°C) | 36.6 |
| timestamp | String | Дата и время добавления | Автоматически |

### HealthStatistics (Статистика)

| Поле | Тип | Описание |
|------|-----|----------|
| totalRecords | Int | Всего записей |
| avgHeartRate | Double | Средний пульс |
| avgSteps | Double | Среднее количество шагов |
| avgBloodPressure | Double | Среднее верхнее давление |
| avgWaterIntake | Double | Среднее потребление воды |

---

## 6. МЕДИЦИНСКИЕ НОРМЫ (ОЦЕНКА ПОКАЗАТЕЛЕЙ)

| Показатель | Норма | Предупреждение | Критично |
|------------|-------|----------------|----------|
| **Пульс** | 60-100 уд/мин | <60 или >100 | — |
| **Шаги** | 5000-10000 | <5000 | >10000 ("Отлично!") |
| **Давление** | сист.<120, диаст.<80 | сист.120-130 | сист.>130 |
| **Вода** | 1.5-2.5 л | <1.5 л | >2.5 л |
| **Сон** | 6-8 часов | <6 часов | >8 часов |
| **Температура** | 36.2-37.3°C | <36.2°C | >37.3°C |

### Функции оценки в коде

```kotlin
getHeartRateStatus()      // Оценка пульса
getStepsStatus()          // Оценка шагов
getBloodPressureStatus()  // Оценка давления
getWaterStatus()          // Оценка воды
getSleepStatus()          // Оценка сна
getTemperatureStatus()    // Оценка температуры
```

## 7. ХРАНЕНИЕ ДАННЫХ

### Технология
- **SharedPreferences** — лёгкое хранилище в формате ключ-значение
- **Gson** — конвертация объектов в JSON и обратно

### Формат хранения

```json
{
  "history": "[{\"heartRate\":72,\"steps\":8500,\"systolic\":118,\"diastolic\":78,\"waterIntake\":1.8,\"sleepHours\":7,\"temperature\":36.6,\"timestamp\":\"30.05.2026 14:30\"}, ...]"
}
```

### Ограничения
- Максимум 100 записей в истории
- При добавлении 101-й записи самая старая удаляется

## 13. ИЗВЕСТНЫЕ ОГРАНИЧЕНИЯ

| № | Ограничение | Описание |
|---|-------------|----------|
| 1 | **API 26+** | Использует LocalDateTime, не работает на Android 7 и ниже |
| 2 | **God Activity** | Вся логика в одном файле (370+ строк) |
| 3 | **Нет графиков** | Нет визуализации динамики показателей |
| 4 | **Нет экспорта** | Нельзя выгрузить данные |
| 5 | **Нет напоминаний** | Пользователь сам должен помнить о замерах |
| 6 | **Нет валидации** | Можно ввести пульс 1000 — приложение покажет "Нормальный" |
| 7 | **Только систолическое** | Статистика давления учитывает только верхнее значение |

## 14. ИЗМЕНЕНИЯ В КОДЕ (ДЛЯ РАЗРАБОТЧИКОВ)

### 14.1 Добавление нового показателя

1. Добавить поле в `HealthData`
2. Добавить поле в диалог `showAddDataDialog()`
3. Добавить карточку в `addMetricsSection()`
4. Добавить функцию оценки `getNewMetricStatus()`
5. Обновить статистику в `getStatistics()`

### 14.2 Изменение медицинских норм

Отредактировать соответствующие функции:

```kotlin
getHeartRateStatus()      // Строка: rate in 60..100
getStepsStatus()          // Строка: steps in 5000..10000
getBloodPressureStatus()  // Строка: systolic < 120 && diastolic < 80
```

### 14.3 Очистка всех данных

```kotlin
healthDataManager.clearAllData()  // Добавить кнопку в UI
```
